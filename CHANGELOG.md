# Changelog

## 0.1.0

First public cut.

- Windows portable zip (double-click `LazyCatter.exe`, no Python required for end users)
- Step wizard (Connect → Plan → Move → Execute), skippable, header STOP
- Channel/thread picker after connect
- Copy messages between channels via webhook (whole-thread for library dumps)
- Roles in plan.yaml (create/edit/reorder, never delete)
- Save to restore / Export template plans
- First-run toast, status pill stays a circle when stopped
- Claude plan skill under `skill/lazycatter/`
- Optional Docker path for people who want containers
- Portable zip unsigned unless you sign locally
